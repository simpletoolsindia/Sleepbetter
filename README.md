# SleepBetter

Android (Kotlin + Jetpack Compose) app for focus, reading and sleep. It combines a natural ambient sound mixer (rain, thunder, tent, car, campfire, forest, birds, water drops, noise and focus music), timed loop playback, sleep tracking, bedtime reminders, a sleep-health score, and animated sleepy-animal characters.

- Research and product plan: [docs/RESEARCH_AND_PLAN.md](docs/RESEARCH_AND_PLAN.md)
- Sound licence register: [sounds/LICENSES.csv](sounds/LICENSES.csv). Every audio file shipped must have a row here.
